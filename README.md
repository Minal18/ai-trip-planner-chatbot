# AI Trip Planner Chatbot

A conversational chatbot UI that helps users plan and book trips end-to-end using AI — intelligently searching flights and stays, building itineraries, and handling bookings through natural conversation.

## Architecture

See [docs/architecture.md](docs/architecture.md) for the full multi-agent architecture (supervisor + sub-agents built on LangGraph, with MCP servers wrapping external travel APIs).

**MVP scope:** flights and hotels.
**Roadmap:** activities, rental cars, restaurants.
